圖解二次不等式 4 大核心步驟

DSE 必考法寶
1
求 x 軸截距 解方程 \( ax^2 + bx + c = 0 \)，利用因式分解法或公式求出根 \(\alpha\) 及 \(\beta\)。
2
判斷拋物線開口方向 • 若 \(a > 0\)：開口向上 (∪)
• 若 \(a < 0\)：開口向下 (∩)
3
對照目標不等號區域 • \(y > 0\) 或 \(\ge 0\)：取 x 軸上方 圖像（螢光藍）
• \(y < 0\) 或 \(\le 0\)：取 x 軸下方 圖像（霓虹粉）
4
讀出 x 軸投影範圍（最終解） 注意：大於小於號「不含邊界」畫空心點；包含等於號「含邊界」畫實心點。
